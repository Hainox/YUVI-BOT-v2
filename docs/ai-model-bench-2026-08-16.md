# AI-бенчмарк моделей OpenCode Go — 2026-08-16

Дата: 2026-08-16. Гейтвей: `https://opencode.ai/zen/go/v1`, новый ключ владельца.
Методика: `scripts/model_bench.py` — формы `twin` / `topics` / `joke` / `complaints`
(представительные промпты бота), `max_tokens=1500` (как в боте), `temperature=0`,
2 прогона на каждый результат. Метрики: успех (непустой content без `<think`-утечки),
латентность, стабильность (доля успешных прогонов).

## Ключ и окружение

- Старый ключ в `.env` был мёртвым (401 `Invalid API key`) — заменён на новый.
- В пользовательском окружении Windows оставались устаревшие
  `OPENAI_API_KEY=%API_KEY%` и `OPENAI_BASE_URL=https://openrouter.ai/api/v1`,
  которые перекрывают `.env` (python-dotenv не перезаписывает существующие env) —
  локальные запуски уходили в OpenRouter с мусорным ключом. Почищено вручную
  (`setx ... ""`).
- `GET /models` на обоих гейтвеях публичный (200 без ключа) — сам по себе
  «успешный» запрос каталога ключ не проверяет.
