# Заметки для Claude Code

## Деплой

Эта среда — удалённая сессия без прямого доступа к прод-VPS (нет SSH). Деплой
всегда делает владелец бота вручную на сервере.

Прод-сервер: `82.23.173.215`, домен `yuvibot2.xyz` (владелец подключается сам
через SSH, `root` — эта сессия сама не подключается и не хранит пароль).
Пробный `WebFetch` на `https://yuvibot2.xyz/` вернул пустой ответ — не
факт, что это ошибка (может быть SPA-шелл без JS-рендеринга в fetch'е), но
статус эндпоинта этим не подтверждён; перепроверяй перед тем, как полагаться
на публичную доступность.

**После каждого мёржа в `main` всегда указывай точную команду для деплоя** —
не просто сообщай, что смёржено. Проверь, какие сервисы из `docker-compose.yml`
реально задел диф (обычно `bot`; `api`/`miniapp` — если менялись
`api/`/`miniapp/`), нужна ли миграция (`alembic upgrade head` — только если
менялась модель в `common/models`), и явно предупреждай, если новый
`.env.example`-дефолт не подхватится без ручной правки уже существующего
прод-`.env` (см. `docs/deploy-vps-ubuntu.md`).

Базовый шаблон:

```bash
cd yuvi-bot-v2
git pull origin main
docker compose up -d --build <service...>
```
