# Заметки для Claude Code

## Деплой

Эта среда — удалённая сессия без прямого доступа к прод-VPS (нет SSH, нет
публичного health-эндпоинта в `.env.example`/`DOMAIN`). Деплой всегда делает
владелец бота вручную на сервере.

**После каждого мёржа в `main` всегда указывай точную команду для деплоя** —
не просто сообщай, что смёржено. Проверь, какие сервисы из `docker-compose.yml`
реально задел диф (обычно `bot`; `api`/`miniapp` — если менялись
`api/`/`miniapp/`), нужна ли миграция (`alembic upgrade head` — только если
менялась модель в `common/models`), и явно предупреждай, если новый
`.env.example`-дефолт не подхватится без ручной правки уже существующего
прод-`.env` (см. `docs/deploy-vps-ubuntu.md`).

Базовый шаблон:

```bash
cd yuvi-bot-v2
git pull origin main
docker compose up -d --build <service...>
```
